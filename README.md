# honto_library_extension

## 概要
hontoのウィッシュリストを開くだけで、登録した本が地元の図書館にあるかどうかを自動的に確認するGoogle Chrome拡張機能です。

【主な機能】
・ウィッシュリストの全書籍を一括チェック
・蔵書あり（貸出可）・予約のみ・蔵書なしをバッジで表示
・「蔵書あり」の場合は図書館の予約ページへ直接リンク
・都道府県・市区町村から図書館を検索して設定

【使い方】
1. 拡張機能のオプションページで都道府県・市区町村を選択し、図書館を設定
2. hontoのウィッシュリストページを開くと自動でチェックが始まります

蔵書情報はCALIL（カーリル）APIを利用しています。

## プライバシーポリシー

本拡張機能はユーザーの個人情報を収集・送信しません。
設定情報（図書館名・システムID）はお使いの端末内にのみ保存されます。
hontoウィッシュリストから取得したISBNはCALIL APIへの問い合わせにのみ使用し、外部サーバーへの記録は行いません。
